# Caveman Stats

Cuando se invoque este comando (`/caveman-stats` o consulta de estadísticas de tokens):
1. Reportar el estado de tersura activo (lite, full, ultra, off).
2. Reportar estimación cualitativa/cuantitativa de concisión y ahorro de contexto en la conversación actual.
3. Recordar los comandos rápidos para ajustar la intensidad (`/caveman lite|full|ultra` o `stop caveman`).
